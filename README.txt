DESHMUKH FARM'S WEBSITE — ANDROID SETUP

WHAT'S INCLUDED
- index.html: mobile-friendly website
- images/: image slots for your real farm and equipment photos

IMPORTANT BEFORE PUBLISHING
1. The images folder contains no actual farm photos. Add your own images using the exact filenames listed below.
2. Confirm the phone number, Instagram, business description, product categories and Google Maps pin are correct.
3. Remove product categories that you do not actually supply.

IMAGE FILES TO ADD (JPG OR PNG, JPG filenames easiest)
- farm-hero.jpg     Main banner / tractor or farm photo
- plough.jpg        Plough
- cultivator.jpg    Cultivator
- rotavator.jpg     Rotavator
- seed-drill.jpg    Seed drill
- trailer.jpg       Trailer/trolley
- farm-tools.jpg    Other tools
- your-farm.jpg     Your own farm photo
- gallery-1.jpg     Farm gallery photo
- gallery-2.jpg     Equipment gallery photo
- gallery-3.jpg     Farm/crop photo

HOW TO PUBLISH FREE WITH GITHUB PAGES ON ANDROID
1. Open https://github.com in Chrome and sign in.
2. Create a new repository named deshmukh-farms-website.
3. Set it to Public. Create repository.
4. Open the repository and choose Add file > Upload files.
5. Upload index.html and upload all image files into an images folder. On GitHub, create the images folder by using Add file > Create new file and entering images/.gitkeep, commit it, then upload image files into that folder. Alternatively upload the whole folder using a GitHub-supported upload flow if available.
6. Commit the files.
7. Open repository Settings > Pages.
8. Under Build and deployment, choose Deploy from a branch.
9. Select branch main and folder /(root), then Save.
10. Wait a few minutes, then return to Settings > Pages and open the published URL. It usually looks like https://YOUR-USERNAME.github.io/deshmukh-farms-website/
11. Open the live link on your phone and test WhatsApp, Instagram and Maps buttons.

IF YOU ALREADY HAVE A GITHUB REPOSITORY
Upload/replace index.html and add the images folder to the existing repository. Do not create a second repository unless you want a separate website.

TROUBLESHOOTING
- If images are missing, filenames and capitalization must match exactly.
- If the website does not load, make sure index.html is in the repository root and Pages is enabled for main /(root).
- If the page shows 404, wait a few minutes and check Settings > Pages for the exact published URL.
- GitHub Pages may take several minutes to publish changes.
